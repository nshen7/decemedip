# Package index

## All functions

- [`decemedip-package`](https://nshen7.github.io/decemedip/reference/decemedip-package.md)
  : The 'decemedip' package.

- [`decemedip()`](https://nshen7.github.io/decemedip/reference/decemedip.md)
  : Main function to perform cell type deconvolution with MeDIP-seq data

- [`getRoiReadCount()`](https://nshen7.github.io/decemedip/reference/getRoiReadCount.md)
  : Obtain read counts of regions of interest from MeDIP-seq bam files

- [`getSummaryOnPi()`](https://nshen7.github.io/decemedip/reference/getSummaryOnPi.md)
  : Extract summary statistics and diagnostics on fitted cell type
  proportions

- [`hg19.ref.anc.se`](https://nshen7.github.io/decemedip/reference/hg19.ref.anc.se.md)
  :

  Hg19 genomic information of anchor CpGs (i.e., all-tissue
  unmethylated/methylation probes) inferred from DNA methylation atlas
  published by Moss 2018 Nat. Commun.
  (https://www.nature.com/articles/s41467-018-07466-6). Used as default
  in `decemedip`.

- [`hg19.ref.cts.se`](https://nshen7.github.io/decemedip/reference/hg19.ref.cts.se.md)
  : Hg19 genomic information of cell-type-specific marker CpGs inferred
  from DNA methylation atlas published by Moss 2018 Nat. Commun.
  (https://www.nature.com/articles/s41467-018-07466-6).

- [`hg38.ref.anc.se`](https://nshen7.github.io/decemedip/reference/hg38.ref.anc.se.md)
  : Hg38 genomic information of cell-type-specific marker CpGs inferred
  from DNA methylation atlas published by Moss 2018 Nat. Commun.
  (https://www.nature.com/articles/s41467-018-07466-6).

- [`hg38.ref.cts.se`](https://nshen7.github.io/decemedip/reference/hg38.ref.cts.se.md)
  : Hg38 genomic information of cell-type-specific marker CpGs inferred
  from DNA methylation atlas published by Moss 2018 Nat. Commun.
  (https://www.nature.com/articles/s41467-018-07466-6).

- [`makeReferencePanel()`](https://nshen7.github.io/decemedip/reference/makeReferencePanel.md)
  :

  Function for assembling a SummarizedExperiment object of reference
  panel in **hg19** for cell type deconvolution (which is used in
  `decemedip` function)

- [`pdx.counts.anc.se`](https://nshen7.github.io/decemedip/reference/pdx.counts.anc.se.md)
  : MeDIP-seq read counts on reference anchor CpGs of 3 PDX samples from
  Berchuck et al. 2022

- [`pdx.counts.cts.se`](https://nshen7.github.io/decemedip/reference/pdx.counts.cts.se.md)
  : MeDIP-seq read counts on reference cell type-specific CpGs of 3 PDX
  samples from Berchuck et al. 2022

- [`plotDiagnostics()`](https://nshen7.github.io/decemedip/reference/plotDiagnostics.md)
  :

  Diagnostics for model fitting in `decemedip`
