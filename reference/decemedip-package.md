# The 'decemedip' package.

The R package decemedip is a novel computational paradigm developed for
inferring the relative abundances of cell types and tissues from tissue
bulk or circulating cell-free DNA (cfDNA) measure by methylated DNA
immunoprecipitation sequencing (MeDIP-Seq). This paradigm allows using
reference data from other technologies such as microarray or WGBS.
